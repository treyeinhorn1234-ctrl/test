# Quêtes — à venir (Étape 5)

Module réservé au journal de quêtes (touche **J**) : quêtes principales et
secondaires, objectifs, récompenses, événements modifiant le monde.

État actuel (Étape 1) : l'objectif courant est piloté par
`world/EncounterDirector.ts` et affiché dans le HUD (haut droite) via
l'événement `objective`. La touche J affiche un message indiquant l'étape prévue.
